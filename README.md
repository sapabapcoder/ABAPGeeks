# CRUD (Create, Read, Update, Delete) in ABAP - ABAPGeeks.com

In SAP ABAP, CRUD operations: Create, Read, Update, and Delete are fundamental for interacting with database tables. These operations form the backbone of any database-driven application, enabling you to manage and manipulate data effectively.

In this [ABAP CRUD Tutorial](https://abapgeeks.com/how-to-create-read-update-delete-crud-entries-in-custom-transparent-table-using-abap/) you will learn on hot to implementing CRUD operations in ABAP. By the end of this guide, you will learn how to:

1. Create: Insert new records into a database table.
2. Read: Retrieve existing records from a database table.
3. Update: Modify existing records in a database table.
4. Delete: Remove records from a database table.

## Pre-requisites for This Tutorial

Before starting, ensure you meet the following requirements:

1. FLIGHT DATA Model (SAP Mockup table for testing). These tables are available in your SAP system, but if the records are empty, you can regenerate the tables first using out tutorial on [How To Create FLIGHT Tables](https://abapgeeks.com/how-to-create-flight-mockup-tables-in-sap/).
2. Access: Developer access key to the SAP system to create programs and test CRUD operations.

## Structure of the Tutorial

1. Create Operation: Learn how to insert new data into a table using the INSERT statement.
2. Read Operation: Understand how to retrieve data using SELECT statements with filtering and sorting.
3. Update Operation: Modify specific records in the table using the UPDATE statement.
4. Delete Operation: Remove data from the table using the DELETE statement.
5. Error Handling: Implement SY-SUBRC checks to handle errors effectively during CRUD operations.
